# 数智中心大屏聚合平台（TV Show Center）

面向小米电视（Android TV / MIUI TV）等安卓大屏设备的**大屏展示聚合应用**：首页以卡片宫格聚合多个大屏入口，点击后通过 WebView 加载指定的 Web 大屏页面，并把电视遥控器按键完整映射到页面内元素（焦点移动 / 触发点击）。

采用 **C/S 架构**，职责边界清晰：

- **服务端（内容）**：页面列表、系统标题是唯一数据源，日常增删改内容**无需重新安装 APK**；
- **客户端（展示策略）**：**是否轮询、轮询哪些页面与间隔、2×2 分区各放什么**都是本机设置，各台电视互不影响；
- **多设备互控（2.0 新增）**：**独立控制台 `/console`**（平板存书签即用，自身不受控）对全场设备（电脑 / 平板 / 电视）单台 / 群组 / 一键场景地下发「显示某页 / 轮询 / 2×2 分屏 / 回首页 / 刷新」；电脑 / 平板显示端被控时**只切画面、不锁鼠标**；电视端锁定遥控按键并以【菜单】首项开关交还（退出需二次确认），见[多设备互控](docs/架构与实现.md#多设备互控远程控制)。

遥控器交互（本版按现场反馈调整，进入即配置）：

| 操作 | 结果 |
| --- | --- |
| 首页按【菜单】→「轮询展示」 | **直接进入轮询播放**，无需先做任何设置（首次进入默认轮询全部页面） |
| 轮询播放页再按【菜单】 | 弹出控制菜单，其中「轮询设置」可打开设置界面（开关 / 间隔 / 页面与顺序） |
| 首页按【菜单】→「分区展示（2×2 拼接）」 | **直接进入 2×2 拼接页**，方向键选格、按【确定】为该格选页面 |

- 应用包名：`com.digitalcenter.tvshow`
- 客户端版本：`2.0`（versionCode 23）· **多设备互控**：远程控制台 `/console`（单文件页，平板书签直达，自身不注册受控）对全场设备下发显示 / 轮询 / 分屏 / 场景，**离线设备自动拦截不发送**；电脑 / 平板显示端被控只切画面不锁鼠标，现场本地操作偏离指令画面即自动回到本地控制；电视端锁定遥控按键（【返回】放行）；**移除断电重启自动恢复——设备重开/回归即本地控制**；场景预设（一键切换）与同相轮询（默认关）· 1.7 的旧内核修补与 1920×1080 强制视口全部保留
- 服务端：Node.js 内置模块，入口 `server/server.js`（HTTP 工具 / 数据层 / 路由已拆分为 `server/http-util.js`、`store.js`、`routes.js`），默认端口 `18000`；唯一 npm 依赖 `esbuild` 仅用于「旧内核兼容转译」，可不装；控制通道 `server/ctl.js` 同为零依赖
- 最低系统：Android 6.0（API 23），目标 API 34，横屏全屏

## 快速开始

```bash
node server/server.js                       # 启动服务端（默认 18000，零依赖）
GRADLE_FLAGS=--offline ./scripts/check.sh   # 全量检查：隔离实例回归 + Kotlin 编译（不打包 APK）
```

打包与签名、代码结构见[编译与二次开发](docs/架构与实现.md#编译与二次开发)。
