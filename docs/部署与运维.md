### 安装到小米电视

1. 电视端开启「设置 → 账号与安全 → 未知来源应用安装」，并打开「ADB 调试」。
2. 任选一种方式安装：
   - **U 盘**：把 APK 拷入 U 盘 → 插入电视 → 用电视上的文件管理器点击安装；
   - **adb**：`adb connect <电视IP>:5555` 然后 `adb install -r dist/TvShowCenter-v2.1-release.apk`（versionCode 23 → 24 可直接覆盖升级）。
3. 安装后可在「应用」列表找到「大屏聚合平台」。若出现在 Android TV 风格桌面上，会显示 TV Banner。

## 服务端管理系统与页面配置

日常所有内容维护都在服务端完成，**改完不用碰电视**。

> 接口清单与字段说明见 [API 接口与页面字段](API.md)。

### 启动服务端

```bash
node server/server.js                    # 默认端口 18000
node server/server.js --port 9000        # 指定端口
PORT=9000 node server/server.js          # 或用环境变量
node server/server.js --host 127.0.0.1   # 只监听本机（配合反向代理更安全）
```

启动后：

| 地址 | 用途 |
| --- | --- |
| `http://<服务器IP>:18000/` | **电脑浏览器客户端（站点首页）**，别名 `/app`、`/client` |
| `http://<服务器IP>:18000/console` | **设备控制**（客户端「设备控制」screen 的直达别名，平板可存书签） |
| `http://<服务器IP>:18000/setting` | **管理（设置）页面**，别名 `/admin` |
| `http://<服务器IP>:18000/preview` | **电视端 1:1 预览页**，别名 `/preview.html` |
| `http://<服务器IP>:18000/api/config` | 客户端拉取接口 |

> 三个页面与所有接口**共用 18000 一个端口**，服务端不会启用第二个端口。首页顶栏的「更多 ▾」二级菜单内置了**「电视端预览」→ `/preview`** 与 **「设置」→ `/setting`** 两个跳转入口。
>
> **升级注意**：页面文件（客户端 / 管理页 / 控制台 / 预览页）是每次请求都读盘的，替换文件即生效；但 **`server.js` 及其模块（`ctl.js` 等）的变更必须重启服务端进程**才能生效——例如 2.0 新增的 `/console` 路由与 `/api/ctl/*` 接口，只替换页面文件不重启会得到 `{"error":"未找到接口 GET /console"}`。重启不影响数据（`config.json` / `devices.json` 均在磁盘）。

通常无需 `npm install`：服务端只用到 Node 内置模块，把 `server/` 目录拷到任意装了 Node 的机器即可运行（内网离线环境同样适用）。**唯一例外**是「旧内核兼容转译」：需要联网执行一次 `npm install` 安装 `esbuild`；不装也能正常启动，只是该功能不生效（自动退回原样透传）。

### 管理后台能做什么

| 功能 | 说明 |
| --- | --- |
| **系统标题修改** | 主标题、副标题、退出提示文案、是否弹退出确认；保存即写入服务端 |
| **新增页面** | 标题、描述、URL、图标、主题色、缩放、自动登录账号密码与选择器、强制原址打开、history 路由 SPA、旧内核兼容转译（含 `compatTarget`） |
| **编辑 / 删除页面** | 表格行内操作，删除后电视端不再显示该入口 |
| **排序** | 上移 / 下移，对应电视端首页宫格的排列顺序 |
| **状态栏** | 当前 `version` / `epoch` / 页面数 / 更新时间 |
| **强制客户端全量刷新** | 担心某台设备数据不一致时，让所有客户端下次同步重拉全量 |

> 轮询与分区**不在管理后台**：它们是每台电视自己的展示策略，见[架构与实现](架构与实现.md)的「轮询展示」「分区展示」。

### 电视端如何生效

内容改动后，电视端在以下时机自动应用（**无需重装应用**）：

1. **应用启动时** —— 自动比对版本，有变更即增量更新；
2. **回到前台时** —— 距上次同步超过 15 秒则同步一次；
3. **按遥控器【菜单】键 →「立即同步配置」** —— 手动同步，底栏会提示结果；
4. **内容变更即时推送（2.0 新增）** —— 服务端在 3 秒心跳响应中携带内容版本（`content.version/epoch`），客户端发现落后于服务端即**立即强制同步**：Web 管理后台保存后，全场电视 / 电脑显示端 **≤3 秒**拿到新内容，无需重启或手动操作（5 秒防抖避免同步失败期间每拍重试）。

底栏右侧会常显同步状态：`已同步 vN` / `同步中…` / `离线（使用缓存）`。

### 客户端服务器地址

按交付约定地址**打包内置**在 `app/src/main/assets/config.json` 的 `serverBaseUrl`：

```json
{
  "serverBaseUrl": "http://10.8.11.4:18000",
  "sync": { "connectTimeoutMs": 3000, "readTimeoutMs": 5000, "pollIntervalSec": 0, "minSyncIntervalMs": 15000 },
  "fallback": { "appTitle": "...", "entries": [ ... ] }
}
```

- 部署到你们内网时，把 `serverBaseUrl` 改成实际服务器地址后重新出包即可（改这一行）。
- 现场需要**临时切换服务器**又不想重装时，可把同名文件放到
  `/sdcard/Android/data/com.digitalcenter.tvshow/files/config.json`（优先级高于包内，`adb push` 即可），无需重新出包。
- `fallback` 是**兜底内容**：首次安装、服务器不可用、或配置还没同步下来时显示，保证电视端永远有内容。


## 安全与注意事项（服务端）

### 服务端与安全

1. **管理后台内网免鉴权（重要）**：按交付约定不设登录，因此**同网段任何人都能打开后台并修改内容**。请务必：
   - 只在内网部署，不要映射到公网；
   - 用防火墙限制来源网段（只允许运维机访问 18000 端口）；
   - 需要更严的隔离时，用 `--host 127.0.0.1` 只监听本机，前面挂一个带认证的反向代理。
2. **数据备份**：全部数据就是单个 `server/data/config.json`，定期备份该文件即可（服务端每次写入会自动保留 `.bak`，主文件损坏时启动会自动回退）。删除该文件后再启动会重新生成初始数据。
3. **服务端地址是打包内置的**：换服务器需要改 `app/src/main/assets/config.json` 的 `serverBaseUrl` 后重新出包；现场临时切换可把同名引导文件推到设备外部目录（见上文「客户端服务器地址」），无需重装。
4. **密码明文存放**：自动登录账号密码以明文存在于服务端 `server/data/config.json`，并会下发到客户端缓存。请限制服务端的访问范围。


## 部署自检清单

### 服务端（部署后先在电脑上确认）

1. `node server/server.js` 能正常启动，且**只监听 18000 一个端口**（`ss -ltnp | grep 18000`），没有第二个端口；
2. 三个地址逐个打开、确认各自是**正确的页面**（不串页、不 404）：
   - `http://<服务器IP>:18000/` → **电脑端客户端首页**（卡片宫格 + 时钟）；
   - `http://<服务器IP>:18000/setting` → **管理（设置）页面**（页面列表 + 系统标题）；
   - `http://<服务器IP>:18000/preview` → **电视端 1:1 预览页**（1920×1080 舞台 + 虚拟遥控器）；
3. 在首页顶栏点「更多 ▾」，确认菜单里「本机设置」「立即同步配置」可用，「电视端预览」「设置」能分别跳到上面两个页面（新标签打开），且点页面别处或按 `Esc` 会自动收起菜单；
4. 在 `/setting` 改一次系统标题、新增一个页面、上移/下移一次，刷新页面确认都已保存（版本号递增）；
5. 用另一台机器（不是服务器本机）访问 `/setting`，确认网络可达、防火墙已放行；
6. 确认管理页**只有**页面管理与系统标题两块，没有轮询/分区面板（这两项归客户端）；
7. 回到首页 `/`，确认卡片数量与后台页面数一致、标题居中、时钟走动；
8. 点一张**无需登录**的卡片，确认页面在浏览器里正常显示、**鼠标可直接点击页面内的元素**，`Esc` 返回首页；
9. 点一张**配了自动登录**的卡片（默认走代理），确认顶栏显示「代理」、页面**自动完成登录**；
   若目标页异常，点顶栏「直连」切换后重试，确认两种方式都能打开（切换结果会记住）；
10. 点「轮询展示」确认**直接开始轮播**，状态条显示「轮询播放中 · 第 x/n 页 · Ns 后切换」，`空格` 可暂停/继续；
   进「本机设置」改间隔与参与页面（↑↓ 调序），确认刷新页面后设置仍在；
11. 点「分区展示」：点击某格「选择页面」为它指定大屏，确认其余格不重载；方向键移动确认只有高亮变化（四格画面不闪断）；
12. 复制一份 `server/data/config.json` 作为初始备份。

> **（可选）启用旧内核兼容转译时另查**：`cd server && npm install` 装好 `esbuild` 后重启服务端；
> 访问 `/api/admin/health`，确认 `transpile.available` 为 `true`、`version` 有值；
> 在 `/setting` 给目标入口勾选「旧内核兼容转译」并保存；
> 浏览器打开 `http://<服务器IP>:18000/proxy/<入口id>/<页面路径>`，确认页面正常且控制台无 `Unexpected token` 类语法报错。

### 电视端（装包后确认）

13. 启动应用：**首屏是否立即出内容**（不等网络），底栏右侧是否显示同步状态；
14. 服务器上把某个页面标题改掉 → 电视上按【菜单】→「立即同步配置」→ 底栏提示「已从服务器更新到 vN」且标题已变；
15. 在管理后台新增／删除一个页面 → 电视端同步后入口数量随之变化，**全程无需重装**；
16. **停掉服务端**后重启电视应用：仍显示上次同步的内容并标注「离线」；恢复服务端后按【菜单】可继续同步；
17. **首页【菜单】是否弹出控制菜单**（4 项：立即同步配置 / 轮询展示 / 分区展示（2×2 拼接） / 关闭）——若按【菜单】没有反应，先确认遥控器该键发出的是 `KEYCODE_MENU`（可用 `adb shell getevent` 观察）；
18. **轮询进入即播**：按【菜单】→「轮询展示」，是否**直接开始轮播**、右上角显示「轮询 N/M · 剩余 N 秒」（首次进入默认全部页面参与）；在轮询播放页**再按一次【菜单】**，控制菜单首项是否为「轮询设置」；
19. **轮询设置**：进入「轮询设置」后把间隔改为 10 秒、移出 1 个页面、按【左/右】调整顺序；按【返回】确认回到**轮询播放**（不是首页）且新设置立刻生效；「开机自动播放」开启后重启应用，确认自动进入轮询；关闭后重启确认停在首页、但【菜单】→「轮询展示」仍可手动进入；
20. **分区展示（进入即配置）**：按【菜单】→「分区展示（2×2 拼接）」直接进页面；方向键是否能在 2×2 之间移动当前分区（含未配置的格）且**目标格亮一下就消失**（不留常驻边框）、移动时四格画面**不应闪断重载**、按【确定】是否弹层可选页面（含「不使用」）；选好后该格是否立即加载、其余格不受影响；按【菜单】是否弹出「刷新全部页面 / 返回首页」；确认**没有**独立的"分区设置"界面；
21. 逐个进入大屏：页面是否铺满屏幕（无黑边、无裁切），需登录的大屏是否自动完成登录；
22. 在大屏页按方向键，焦点是否在按钮/页签等可交互元素间移动，按确定是否触发对应操作；按【菜单】可刷新与缩放；
23. 在首页按【返回】，确认弹出退出确认框且默认焦点在【取消】；
24. **设置是否持久化**：设置好轮询与分区后，用 `adb shell am force-stop com.digitalcenter.tvshow` 杀掉进程再打开，确认设置仍在（存于本机 SharedPreferences）；
25. **长时间运行**：分区展示连续跑 30 分钟以上，观察是否卡顿、掉线或 WebView 被回收（4 个 WebView 同时运行对性能有要求，必要时减少同时配置的格位）。

### 多设备互控（2.0 装包 / 打开后确认）

26. 平板打开 `/console`（独立控制台；也可从显示端首页顶栏「远程控制」按钮进入）：全场设备（电脑 / 平板显示端 / 电视）是否都已出现、在线点是否为绿；电视默认名「新设备-xxxx」可点按重命名；**控制台自身不出现在列表里**；
27. 只勾选一台电视 →「显示页面」选某页 → 电视 **≤3 秒**切换并出现「远程被控」角标；按遥控器方向键应只弹 Toast「远程被控中」；
28. 电视受控时按方向 / 确定 /【菜单】键：仅弹 Toast「远程被控中 · 可按【返回】退出当前画面」；按【返回】可正常退出当前画面回首页（受控端无取消按钮，退出即本地操作）；控制台对该电视点「取消控制」→ 电视 ≤3 秒解锁、角标消失、画面保持，卡片变「本地控制」；
29. 再对该电视下发任意展示指令 → 电视自动切回被控（开关不构成否决权）；
30. 逐台各显不同画面：只勾「一号电视」选画面1 → 只勾「二号电视」选画面2 → 只勾某电脑选画面3，三台各自生效互不影响；
31. 对一台电脑显示端下发 `show`：页面切换后**鼠标依旧可点**（点卡片、点顶栏按钮都正常）——电脑 / 平板显示端永不锁定；
