## 优化内容摘要

- **稳定性（阶段 1）**：SIGTERM 优雅退出（先停采集/转码再关 HTTP）；413 先回可读 JSON 再断连；日志轮转 `logrotate`；极速会话目录 0700 / 状态文件 0600。
- **性能（阶段 2）**：本机设置内存缓存；控制台按卡增量刷新且页面隐藏时暂停轮询；首页宫格增量重绑；MJPEG 帧合并丢弃；注入脚本缓存。
- **体验（阶段 3）**：设置页焦点保持、首页空态面板、分区错误重试、被控文案分场景、后台暂停轮询、展示页/分区配置时效、控制台搜索筛选、管理后台自定义确认弹层。
- **结构与可维护性（阶段 4）**：`server.js` 拆为 `http-util` / `store` / `routes`；展示类 WebView 收敛到 `WebViewFactory`；缓存序列化收敛到 `ConfigJson`；README 拆为四篇文档；admin/console 改为模板构建并复用公共片段；Kotlin 单测 17 项；CI 与 `check.sh` 收口。
- **发布准备（阶段 5）**：数据文件权限统一 0600（写入逻辑持久保持）；旧端口注释清理；全量回归 + 线上冒烟 + 构建可复现校验；浏览器端关闭标签页不再弹原生「离开此网站」确认；平板触屏视口下顶栏不再被误判为全屏而隐藏。

### 2026-11-03 补充修复（现场反馈）

- **控制台重命名弹层**：取消「点击遮罩关闭」，平板软键盘弹出导致的可视区域变化不会再误关输入框；仅保留「取消 / 关闭 / Esc」退出。
- **远程极速模式开关**：控制台设备卡按各设备心跳上报的 `turbo` 状态取反下发 `turbo` 指令（服务端归为维护类，不改变受控模式）；电视端 / 网页端应用后按新地址重载当前画面，分区页四格全部重载。
- **极速状态回流修复**：控制台设备卡增量刷新签名补上 `reported.turbo`。此前设备本机切换极速后卡片不重建，控制台一直显示旧状态，且按钮点击取反也基于旧值，造成「上报 / 下发不生效」。
- **控制台新增「首页」入口**：每台设备的显示页面下拉与底部勾选设备下拉均常驻「首页」，可一键让对端回首页（原有「回首页」按钮保留）。
- **控制台设备删除（临时移除）**：设备卡新增「删除」，仅从控制列表暂时移除档案；设备下一次心跳（≤3 秒）会自动重新注册出现，便于现场清理暂时离线的旧设备（不会永久屏蔽任何设备）。
- **控制台卡片信息与类型**：状态顺序固定为「在线/离线 → 本地/远程控制 → 版本 → IP」，在线绿色、离线黄色、本地控制绿色、远程控制蓝色，不再显示「暂无上报」；点击类型标签可在 PC → PAD → TV 间循环切换，手动设置优先于客户端心跳上报。
- **管理后台与远程控制台弹窗关闭逻辑**：所有弹窗取消「点击遮罩关闭」，只能通过「保存 / 确定 / 取消 / 关闭」按钮退出（Esc 等同取消）；安卓端确认框已禁用外部触摸关闭，仅保留「确定 / 取消」。

## 上线步骤（服务端）

1. 备份现场数据：`server/data/config.json`、`server/data/devices.json` 及其 `.bak`。
2. 拉取最新代码并确认工作区只有现场数据改动（`server/data/*` 不提交）。
3. 如需旧内核兼容转译：`cd server && npm install`（可选，缺失时自动退回原样透传）。
4. 重启服务：`systemctl restart tvshow`。
5. 验证：`curl -s http://127.0.0.1:18000/api/admin/health` 返回 200，`version/epoch/entries` 与现场一致。
6. 页面变更后（仅改模板时）：`node tools/build-pages.mjs`（admin/console）或 `node tools/build-client.mjs`（电脑端）。

## 回滚方案

- **服务端代码**：切回上一发布 commit 后 `systemctl restart tvshow`（不要使用会丢弃现场数据的强制清理命令）。
- **数据**：用备份目录中的 `config.json` / `devices.json` 覆盖 `server/data/` 对应文件，重启服务。
- **APK**：小米电视覆盖安装要求 versionCode 严格递增，**已升级的高版本无法降级覆盖**；回滚需卸载后安装旧包，现场需评估。

## 已知限制与遗留项

- **APK 未打包**：按阶段约定仅完成编译与单测；release 签名包与真机安装验证待用户确认后执行。
- **实机 UI 未验证**：开发环境无 KVM 硬件加速，电视端 UI 需按[部署自检清单](部署与运维.md)在真机确认。
- **凭据轮换（A3）**：`keystore/` 与 `gradle.properties` 的默认口令仍为交付示例值，正式外发前应替换。
- **运行期设备数 6 → 7**：新增一台未命名 web 设备档案（`2.0-web`，2026-11-03 注册），属现场使用数据，未做清理；如确认是临时浏览器可让现场自行重命名或忽略。
- **可选依赖**：旧内核兼容转译需 `esbuild`；极速模式需 `playwright-core` + Chromium；摄像头取流依赖现场网络与 ffmpeg。
- **同源风险**：管理接口内网免鉴权，务必用防火墙限制 `18000` 访问范围（见[排障与验证](排障与验证.md)）。
